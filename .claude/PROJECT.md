# Розумничка — лендінг дитячого центру розвитку (Ірпінь)

**Статус:** демо-версія для замовниці, ітерація 2 (15.11.2026): додано анімований перший екран і секцію з формою. Контенту ще немає — всі тексти, цифри, фото та контакти є заглушками. Далі продовжуємо роботу.

## Вихідні дані
- **Структура:** `prototypes/Прототип 4.png` (+ `Прототип 4(модальне).png`, `Прототип напрямки.png`, `Прототип модальне вікно.png`).
- **Стиль / настрій:** референс https://child.mycomputer.education/ — замовниці сподобались **хвилі** між секціями (SVG-хвилі на всю ширину, кольорові секції), м'які «бульбашкові» форми.
- **Кольори та логотип:** зі скріну логотипу (`assets/brand/logo-screenshot.png`): відкрита зелена книга, синя фігурка, рожева шапка випускника.
- `assets/brand/mascot-ref-*.jpeg` — референси маскота (книжка-персонаж), поки не використані.
- **Анімації / перший екран (ітерація 2, 15.11.2026):** референс https://lilokids.framer.website/ — замовниці сподобався перший екран (сад, що росте) та анімації. Взята ідея, не копія: квіти в кольорах бренду, земля = наша зелена хвиля.

## Стек
Чистий HTML + CSS + JS, без збірки і залежностей. Шрифт Nunito (Google Fonts, кирилиця).

```
index.html        — уся розмітка + SEO + Schema.org + SVG-спрайт (хвилі, іконки)
css/style.css     — стилі, змінні кольорів у :root, адаптив внизу файлу
js/main.js        — дані напрямків (COURSES), таби, модалки, форма, меню, анімації
assets/logo.svg   — ТИМЧАСОВИЙ векторний логотип (перемальований), замінити на оригінал
robots.txt, sitemap.xml
prototypes/       — прототипи від замовниці
```

Запуск локально: `python3 -m http.server 8765` у корені → http://localhost:8765

**Хвилі:** два символи `#wave-a` / `#wave-b` у SVG-спрайті. Кожна хвиля стоїть внизу секції (`.wave`), її колір = фон **наступної** секції (`style="color:var(--...)"`). Висота — `--wave-h`. Хвиля hero (`.hero__ground`) — це «земля», з якої ростуть квіти.

## Інтерактив і анімації
**Hero (сад)** — `buildGarden()` у `js/main.js` генерує SVG-квіти (типи `daisy / round / tulip / star`, кольори `BRAND`). Кількість залежить від ширини екрана (6–13). Висота саду — `--garden-h`.
- стебло малюється (`stroke-dashoffset`), потім виростає листок, розпускається голівка (spring);
- квіти постійно гойдаються (`--sway`, `--amp`), нахиляються до курсора (`--lean`); наведення чи клік — голівка крутиться;
- сонце: промені обертаються, очі кліпають, при скролі сонце повертається; хмарки й літери — паралакс від миші (`data-depth`);
- метелик летить по `offset-path`.

**Загальне:** плаваючий хедер-«пігулка» (зменшується при скролі), magnetic-кнопки (`.magnetic`), 3D-нахил карток (`.tilt`, `.card`), reveal з пружиною, лічильники, кнопки з «об'ємною» тінню.

**Напрямки:** картка → модалка «Деталі заняття» → «Записатися» скролить до форми й підставляє напрямок.

**Форма:** валідація (ім'я, телефон 12 цифр, згода) з анімацією «shake», маска `+38 (0XX) XXX-XX-XX`. Під час відправки летить літачок, далі екран «Дякуємо» + конфеті (canvas). **Реальної відправки немає**: див. `// TODO` у `js/main.js`.

Мобільне меню — випадна картка. Для `prefers-reduced-motion` анімації вимикаються.

## Адаптив
Breakpoints: 1024 (планшет landscape), 860 (планшет / бургер), 560 (телефон: ховаються літери в небі, менше квітів). Перевірено на 375, 614, 1300 px — без горизонтального скролу (`overflow-x: clip` на html/body).
